# Store assets

Images for the store listings (Chrome Web Store, Firefox Add-ons, Opera add-ons) and the GitHub repository. Temporary artwork: the logo may be redrawn later.

| File | Size | Where it goes |
|---|---|---|
| `store-icon-128.png` | 128×128 | Chrome Web Store → Store listing → Store icon |
| `promo-small-440x280.png` | 440×280 | Chrome Web Store → Small promo tile |
| `promo-marquee-1400x560.png` | 1400×560 | Chrome Web Store → Marquee promo tile (optional) |
| `social-preview-1280x640.png` | 1280×640 | GitHub → Settings → General → Social preview |

The extension's own icons live in `public/icons/` and are declared in `public/manifest.json`.

Screenshots (1280×800) must be real captures of the extension, not generated images.
